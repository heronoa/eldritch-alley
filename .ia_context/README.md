# AI-assisted work

This folder holds the planning artifacts for work done with AI assistance on this project: implementation plans and their indexes. They are versioned on purpose, so the reasoning behind the code is public along with the code.

Rules for what goes here:

- English only, like the rest of the repository.
- Durable content only: plans, indexes and decisions that outlive the session that produced them.
- Working drafts (for example, merge request descriptions in progress or review notes) stay out of the repository.

Architecture decisions belong in [`docs/adr/`](../docs/adr/), not here. The order of precedence is in [`CLAUDE.md`](../CLAUDE.md): accepted ADRs first, then `CLAUDE.md`, then plans.
