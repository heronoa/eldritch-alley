# rds

One RDS PostgreSQL instance in the isolated subnets, reachable only from the security groups passed in.

- Not publicly accessible, `gp3`, storage encrypted, TLS required (`rds.force_ssl = 1` in the parameter group).
- The master password is generated by RDS and kept in a Secrets Manager secret (`manage_master_user_password`). There is no `password` argument, so it never reaches the state, and no output carries it.
- The security group has no inline rules and no egress; ingress is one separate rule per allowed security group, on 5432, never a CIDR.
- `destroyable = false` (default): deletion protection on and a final snapshot with the fixed identifier you pass. `destroyable = true`: no protection and no snapshot. Delete the previous final snapshot before another teardown, or the second destroy fails loudly.
- No storage autoscaling, no RDS Proxy, no read replicas, no performance insights.
- The application uses the master user in this delivery (a known limitation).

| Input | Description |
|---|---|
| `name`, `vpc_id`, `subnet_ids` | Identity and placement (two isolated subnets) |
| `allowed_security_group_ids` | Groups admitted on 5432 |
| `db_name`, `db_username` | Initial database and master user |
| `instance_class` | Default `db.t4g.micro` |
| `allocated_storage` | Default 20 (GB) |
| `engine_version`, `parameter_group_family` | Default `17` and `postgres17`; the version is a major only |
| `multi_az` | Default `false` |
| `backup_retention_days` | Default 7 |
| `destroyable`, `final_snapshot_identifier` | Teardown behavior; the identifier is required unless destroyable |

| Output | Description |
|---|---|
| `endpoint`, `port`, `db_name`, `username` | Connection pieces. `DATABASE_URL` is assembled in infra-04, not here |
| `master_secret_arn` | Managed secret, a JSON document with a `password` key |
| `security_group_id` | The instance's group |
| `allowed_security_group_ids`, `subnet_ids` | The wiring, echoed for the caller's tests |

Tests: `terraform test` from this directory (mocked provider, no credentials).
