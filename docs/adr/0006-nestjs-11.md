# 0006. NestJS 11 instead of 12

**Status:** Accepted

## Context

NestJS 12 publishes its packages as ES modules (`"type": "module"`). In another project this caused friction with the test runner and with decorator metadata, so the platform stays on NestJS 11 for now.

## Decision

Use NestJS 11 (`^11.2.7`) in `backend/platform-api`. Revisit when the ecosystem around NestJS 12 stabilizes.
