## What this covers

- **Art:** character sprites and their designs, tiles, props, the visual design of maps, user interface art, icons and effects, whether stored as image files or as drawing data in code (for example, the pixel definitions of the class sprites).
- **Setting and writing:** the world, factions, lore, class and ability names and descriptions, in-game text and dialogue.
- **Map designs:** the layouts of the game's maps.
- **Design documents:** art direction, concepts and game design documents.
- **Audio:** music and sound effects, when added.

These assets live mainly in:

- `frontend/src/assets/`
- `frontend/public/`
- `docs/`
